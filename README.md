# 🎓 Student Management System

A simple Student Management System built with **Java** and **Spring Boot** for learning and practice purposes.

## 🚀 Features

* Add, update, delete, and view students
* RESTful APIs using Spring Boot
* Database integration with Spring Data JPA
* Clean and structured backend architecture

## 🛠️ Tech Stack

* Java
* Spring Boot
* Spring Data JPA
* MySQL
* Maven

## 📚 Purpose

This project was created to strengthen my understanding of Java backend development, Spring Boot, REST APIs, and database operations.
